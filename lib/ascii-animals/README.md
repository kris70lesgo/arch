# ASCII Animals renderer

This directory contains the canvas engine from [DesignerStephen1/ascii-animals](https://github.com/DesignerStephen1/ascii-animals), pinned at commit `0c97cd6b82fb`. Keryx uses its blue morpho butterfly renderer and gridded dark canvas as the animated research workspace background.
